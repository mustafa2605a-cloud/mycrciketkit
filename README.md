# IRONCREASE — Cricket Store (frontend demo)
Vanilla HTML/CSS/JS. No build step, no dependencies.

## Run
1. Extract the ZIP, open the `IRONCREASE` folder in VS Code.
2. Open `index.html` with the Live Server extension (or just double-click it, or run `python3 -m http.server 8000` in the folder and visit http://localhost:8000).
Fonts load from Google Fonts when online; system fonts are used offline.

## Structure
index.html · css/style.css (responsive included) · js/main.js (products, cart, modal, search, animations) · assets/images/

## Needs a real backend/service (currently demo only)
Checkout & payments, real inventory, accounts, order tracking, newsletter subscriptions (validation only), reviews (sample text), legal pages, social links, contact details.

## Images — important
Product photos are crops of the reference photos you supplied; they show other brands' logos (CA, Versus, KG, MRF, FRQ). Replace them in `assets/images/` with your own IronCrease product photography before launch. Edit products/prices at the top of `js/main.js`.
